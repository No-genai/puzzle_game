# 🧩 しゃしんパズル (Photo Puzzle)

写真を撮ったら、その場でパズルになる子供向けアプリです。
**インストール不要・完全オンデバイス**（画像は端末の外に送信されません）。

## 特長

- 📷 **カメラで撮る** or 🖼️ **端末の写真から選ぶ**
- 🧩 撮った写真を自動で正方形に切り抜き、タイルに分割
- 👆 **2枚のタイルをタップして入れ替える**方式（幼児でも直感的に操作可能）
- 🎚️ **難易度を選べる**
  - 😊 とてもかんたん … 2×2
  - 🙂 かんたん … 3×3
  - 😃 ふつう … 4×4
  - 😎 むずかしい … 5×5
- 👀 **おてほん**（完成図）をいつでも確認
- 🔢 **ばんごう**表示のオン/オフ（小さい子のヒントに）
- ⏱️ タイム＆👆 手数カウント、完成すると 🎉 お祝い演出
- 🔒 画像は端末内だけで処理（ネット送信なし）

## つかいかた

### スマホ・タブレットで（おすすめ）

カメラ機能を使うにはHTTPS経由でアクセスする必要があります。かんたんなのは **GitHub Pages** で公開する方法です。

1. GitHub でこのリポジトリの **Settings → Pages** を開く
2. Source を `Deploy from a branch` にして、ブランチを選び `/ (root)` を指定して保存
3. 表示された URL（例: `https://<ユーザー名>.github.io/puzzle_game/`）をスマホのブラウザで開く
4. ホーム画面に追加すると、アプリのように使えます

### パソコンで試す

`index.html` をブラウザで開くだけでも動きます（カメラの代わりに写真ファイルを選択してください）。

ローカルサーバーで動かす場合:

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 技術メモ

- 依存ライブラリなしの単一 HTML ファイル（`index.html`）
- 画像処理は Canvas API、写真取得は `<input type="file" capture>`
- すべてクライアント側で完結（サーバー・通信なし）

## 遊び方のコツ

- まずは **2×2** から。慣れてきたら難易度を上げてください。
- 途中で分からなくなったら **👀 おてほん** で完成図を確認。
- それでも難しければ **🔢 ばんごう** をオンにすると、正しい順番の番号が見えます（1番が左上）。
